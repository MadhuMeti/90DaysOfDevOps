# origin vs upstream
In Git, origin refers to your personal copy of the repository on a remote server (usually your fork), while upstream refers to the original, authoritative repository that you forked from

# git fetch and git pull
The core difference is that git fetch only downloads remote changes without modifying your local working files, whereas git pull downloads those changes and immediately merges them into your active branch

# git clone and git fork
git clone copies a repository to your local computer, while git fork copies a repository on the remote server (like GitHub) to your own server account.

# Squash Commit vs Merge Commit
squash merge combines all feature branch commits into a single commit into the main branch while merge commit stores all the commit history.

# git stash pop vs got stash apply
git stash pop removes the stashed changes from your stash list after applying them, whereas git stash apply leaves the stashed changes intact in your stash list.
